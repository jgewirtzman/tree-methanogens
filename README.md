# Tree Microbiomes and Methane Emissions in Upland Forests

[![DOI](https://zenodo.org/badge/1058191477.svg)](https://doi.org/10.5281/zenodo.18779715)

Analysis code and data processing pipeline for a study of methane fluxes from tree stems and soils at Yale-Myers Forest (YMF), Connecticut, and their relationship to methanogenic and methanotrophic microbial communities.

**Preprint:** [bioRxiv 10.1101/2025.09.30.679632v2](https://www.biorxiv.org/content/10.1101/2025.09.30.679632v2)

The project combines:

- **Flux measurements** — 1,148 stem CH₄ flux measurements from 482 trees plus 276 soil measurements (2020–2023), using semi-rigid and rigid chambers with an LGR3 off-axis ICOS analyzer
- **Molecular quantification** — ddPCR of *mcrA* (methanogens) and *pmoA*/*mmoX* (methanotrophs) from 564 wood and soil samples
- **Community characterization** — 16S rRNA amplicon sequencing, PICRUSt2, FAPROTAX
- **Spatial scaling** — random forest models upscaling plot-level CH₄ flux across the forest inventory

## Getting started

### 1. Data

All data are archived on Zenodo: **[10.5281/zenodo.18779715](https://doi.org/10.5281/zenodo.18779715)**

Download the archive and extract it into `data/` at the repository root. The directory structure is kept in git via `.gitkeep` files, so all paths are pre-configured.

The archive contains:

| Directory | Contents |
|-----------|----------|
| `data/raw/` | Unprocessed instrument and field data |
| `data/processed/` | Intermediate pipeline outputs (regenerable from raw) |
| `data/compiled/` | 20 analysis-ready datasets with documented columns and units — see `README_data.md` in the archive |

Neither `data/` nor `outputs/` is tracked in git; only the folder structure is. Data comes from Zenodo, and everything in `outputs/` is regenerated by the pipeline.

### 2. Environment

R package versions are pinned in `renv.lock` (R 4.4.3). The project activates `renv` automatically via `.Rprofile`:

```r
renv::restore()
```

### 3. Run

All commands are run from the repository root.

```bash
Rscript code/run_all.R            # full pipeline, stages 01-09
Rscript code/make_figures.R       # all publication figures and tables
Rscript code/check_consistency.R  # verify the canonical outputs agree
```

The random forest models are fitted separately, since they take about ten minutes and the specification is fixed:

```bash
cd code/05_model && Rscript 01_load_and_prep_data.R && Rscript 02_rf_models.R
```

`run_all.R` checks for the fitted models and reports the command above if they are missing.

│   ├── 07_molecular/      # gene-flux models, 16S composition, PICRUSt, FAPROTAX
│   │   ├── methanogens/   #   mcrA analyses
│   │   └── methanotrophs/ #   pmoA and mmoX analyses
│   ├── 08_figures/        # figure generators and the figure assembler
│   ├── 09_tables_stats/   # manuscript statistics and summary tables
│   ├── lib/               # shared definitions used across stages
│   ├── zenodo/            # builds the archive in data/compiled/
│   └── archive/           # superseded scripts, kept for reference
└── outputs/
    ├── figures/main/      # numbered main-text figures
    ├── figures/SI/        # numbered supplementary figures

Scripts are numbered within each stage to indicate run order. Scripts prefixed `util_` are optional diagnostics.

## Pipeline

| Stage | Purpose | Key outputs |
|-------|---------|-------------|
| `01_import` | Tree-ID consensus, wood cores, internal gas, ddPCR import, stem inventory | `tree_id_comprehensive_mapping.csv`, `processed_ddpcr_data.csv`, `inventory_stems.csv` |
| `02_flux` | Chamber geometry, goFlux flux calculation, quality screens, detection limits | `semirigid_tree_final_complete_dataset.csv`, `methanogen_tree_flux_complete_dataset.csv` |
| `03_merge` | Soil flux correction and harmonization across sources | `merged_tree_dataset_final.csv` |
| `04_drivers` | Reference evapotranspiration, moisture surface, soil temperature climatology | `moisture_surface_grid.csv`, monthly climatologies |
| `05_model` | Random forest fitting, grouped cross-validation, per-species calibration | `RF_MODELS.RData`, `rf_grouped_cv.csv` |
| `06_upscale` | Spatial interpolation, per-stem and soil prediction, stand budget, scaling grid | `canonical_budget.csv`, `scaling_full_grid.csv` |
| `07_molecular` | Gene–flux models, 16S composition, pathway and functional annotation | gene–flux model tables, FAPROTAX exports |
| `08_figures` | Figure generation and assembly of the numbered manuscript set | `outputs/figures/{main,SI}/` |
| `09_tables_stats` | Manuscript statistics and summary tables | `outputs/tables/`, `outputs/audit/` |

`code/09_tables_stats/manuscript_statistics.R` recomputes every quantitative result reported in the manuscript from the underlying data, organized by manuscript section.

`code/check_consistency.R` verifies that the canonical outputs agree with one another — that the budget recomputes from the per-stem predictions, that monthly values sum to annual totals, and so on. It runs in seconds and exits non-zero on failure.

## Figures

```bash
Rscript code/make_figures.R
```

This runs every figure generator and then assembles the numbered manuscript set into `outputs/figures/main/` and `outputs/figures/SI/`. The current set is 9 main-text figures, 25 supplementary figures, photo plates, and 5 tables.

`code/08_figures/rev_00_assemble_figures.R` maps each manuscript figure number to the script output that produces it, and writes `outputs/figures/MANIFEST.md` describing the assembled set.

## Methanotroph definitions

Taxonomy-based methanotroph classification uses a shared definitions table so that all 16S-based figures classify taxa identically.

- `data/compiled/methanotroph_definitions.csv` — curated lookup mapping families and genera to Known, Putative or Conditional status, based on Knief (2015) with SILVA 138 cross-referencing. *Methylacidiphilaceae* is classified as Putative (family-level, genus unresolved).
- `code/lib/load_methanotroph_definitions.R` — provides `classify_methanotrophs()`, `identify_methanotrophs()` and `assign_display_family()`.

Classification hierarchy (first match wins):

1. **Known** — genus on the cultivated methanotroph whitelist (18 genera from Knief Tables 1–3), or an ASV in an exclusively methanotrophic family (Methylococcaceae, Methylothermaceae, Methylomonadaceae)
2. **Putative** — an ASV in a mixed family (Beijerinckiaceae, Methylocystaceae, Crenotrichaceae, Methylacidiphilaceae) whose genus is unresolved
3. **Conditional** — anaerobic methanotrophs (Methylomirabilaceae, *Candidatus* Methylomirabilis), included only when `include_conditional = TRUE`
